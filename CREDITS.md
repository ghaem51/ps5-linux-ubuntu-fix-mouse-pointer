# Credits

The environment variable is an existing GNOME Mutter debug switch, documented by its [native cursor implementation](https://github.com/GNOME/mutter/blob/main/src/backends/native/meta-cursor-renderer-native.c). [Ubuntu pam_env documentation](https://manpages.ubuntu.com/manpages/questing/man8/pam_env.8.html) describes the persistent environment-file mechanism.

This repository distributes its own Python configuration/verification helpers under GPL-2.0-only. No GNOME source or local environment file is included. The implementation and review were assisted by OpenAI Codex. The reported game-stutter symptom comes from the repository owner's PS5 Slim Ubuntu setup, not a benchmark or a claim of upstream endorsement.
